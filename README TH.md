# GARNT TOOL REJOIN — ควายเผือก rejoin

เครื่องมือ auto-rejoin Roblox สำหรับ UG Phone + Termux (Python 3) รองรับหลายโคลน `com.roblox.*`
**ใช้กับบัญชีและอุปกรณ์ของตัวเองเท่านั้น**

---

## 1) ติดตั้งทีละขั้น

### ขั้นที่ 1 — เลือก mirror
```bash
termux-change-repo
```
เลือก "Single mirror" แล้วเลือก mirror ที่ใกล้ที่สุด กด OK

### ขั้นที่ 2 — ติดตั้งด้วยคำสั่งเดียว
```bash
curl -Ls https://raw.githubusercontent.com/Garnt024020806/Free-Tool-Rejoin-Ug-open-source/refs/heads/main/setup.sh | bash
```
สคริปต์จะ: ขอสิทธิ์ storage → อัปเดตแพ็กเกจ → ติดตั้ง python, pip, tsu, libexpat, openssl → ติดตั้ง `rich` และ `requests` → ดาวน์โหลด `rejoin.py` ไปที่ `/sdcard/Download/rejoin.py` และ `~/rejoin.py`

### ขั้นที่ 3 — ตรวจสิทธิ์ต่าง ๆ

| สิทธิ์ | วิธีตั้ง | วิธีตรวจ |
|---|---|---|
| Storage | กด "อนุญาต" ตอน `termux-setup-storage` ขึ้นถาม | `ls /sdcard/Download` ต้องเห็นไฟล์ |
| ปิด Battery optimization | ตั้งค่า → แอป → Termux → แบตเตอรี่ → "ไม่จำกัด" | ตั้งค่า → แบตเตอรี่ → ดูว่า Termux อยู่ในรายการ "ไม่จำกัด" |
| Root | เปิด root ใน UG Phone แล้วกด "Grant" เมื่อ Termux ขอสิทธิ์ | `su -c id` ต้องขึ้น `uid=0` |
| Overlay (non-root) | ตั้งค่า → แอป → Termux → แสดงทับแอปอื่น → เปิด | เข้าหน้าเดิมแล้วดูว่าสวิตช์เปิดอยู่ |

### ขั้นที่ 4 — รัน

**Root (แนะนำ):**
```bash
su -c "export PATH=$PATH:/data/data/com.termux/files/usr/bin && export TERM=xterm-256color && cd /storage/emulated/0/Download && python ./rejoin.py"
```

**Non-root / รันจาก ~:**
```bash
cd ~ && python rejoin.py
```

โปรแกรมตรวจโหมดเองด้วย `su -c id` และใช้ path แบบ absolute จึงรันจากโฟลเดอร์ไหนก็ได้

## 2) ไฟล์และโฟลเดอร์

ทุกอย่างอยู่ที่ `/sdcard/Download/RejoinTool/` (ถ้าเขียนไม่ได้จะใช้ `~/RejoinTool/` แทน)

| ไฟล์ | หน้าที่ |
|---|---|
| `config.json` | ตั้งค่า (merge ค่าเริ่มต้นตอนโหลด, ไฟล์เสียจะสำรองแล้วรีเซ็ต) |
| `cookie.txt` | คุกกี้ 1 บรรทัดต่อ 1 บัญชี |

| `screenshots/` | ภาพหน้าจอ เก็บ 20 ภาพล่าสุด |
| `heartbeat/` | ไฟล์ `.lua` ที่สร้างให้แต่ละโคลน |

## 3) วิธีใช้

1. **เมนู 4** สแกนแพ็กเกจ แล้วเลือกที่จะรัน เช่น `1,3` หรือ `all` (ถ้าไม่พบ ให้พิมพ์ชื่อแพ็กเกจเอง)
2. **เมนู 3** ตั้งลิงก์เกม รองรับ: Place ID, ลิงก์ `roblox.com/games/...`, ลิงก์เซิร์ฟส่วนตัว (`privateServerLinkCode`), share link, `roblox://`
3. **เมนู 1** เริ่มทำงาน — กด `Ctrl+C` เพื่อหยุดและกลับเมนู

### พฤติกรรมหลัก
- ตรวจทุก 30 วิ ทุกอินสแตนซ์ใช้ตารางเวลาเดียวกัน
- เปิดแอป 2 ตัวใด ๆ ห่างกันอย่างน้อย `launch_delay` (ค่าเริ่มต้น 15 วิ) ทั้งตอนเริ่มและตอนรีจอย
- หลังเปิด มีช่วง grace 90 วิ ที่ "ไม่อยู่ในเกม" ไม่นับเป็นความล้มเหลว
- ล้มเหลวซ้ำ → รอ 10, 20, 40 … สูงสุด 300 วิ และรีเซ็ตเมื่อเสถียรต่อเนื่อง 5 นาที

### root / non-root

| ฟีเจอร์ | root | non-root |
|---|---|---|
| ตรวจโปรเซส | ✓ | ✗ |
| ตรวจแอปหน้าจอ (ปิดเป็นค่าเริ่มต้น เพราะหลายโคลนอยู่หน้าจอพร้อมกันไม่ได้) | ✓ | ✗ |
| force-stop ก่อนรีจอย | ✓ | ✗ |
| ภาพหน้าจอ | ✓ | ✗ |
| ฉีดคุกกี้ | ✓ | ตรวจสอบอย่างเดียว |
| เคลียร์ RAM | ✓ | ✗ |
| สถานะจาก presence API (ต้องมีคุกกี้) | ✓ | ✓ |
| รีจอยตามเวลา (นาที) | ✓ | ✓ |

ถ้า non-root และไม่มีคุกกี้ สถานะจะแสดง "ไม่ทราบ" — เปิด "รีจอยตามเวลา" ในเมนู 6 เพื่อให้รีจอยเป็นรอบ

## 4) ล็อกอินด้วยคุกกี้ (เมนู 5)

- ใส่คุกกี้ใน `cookie.txt` บรรทัดละ 1 บัญชี รับรูปแบบ `.ROBLOSECURITY=...` และมีเครื่องหมายคำพูดได้ บรรทัดว่างและ `#` จะถูกข้าม
- คุกกี้จับคู่กับ **ทุกแพ็กเกจที่สแกนพบ** ตามลำดับ (บรรทัดที่ 1 → แพ็กเกจที่ 1)
- ตรวจแต่ละคุกกี้กับ API แล้วแสดงชื่อผู้ใช้
- root: force-stop → คัดลอกฐานข้อมูล WebView `Cookies` ออกมา → แก้ตามสคีมาของตาราง → คัดลอกกลับพร้อม `chown`/`chmod`/`restorecon`
- คุกกี้ถูกปิดบังในทุกที่แสดงผล ไม่ถูกเขียนลง log, config.json หรือ webhook

## 5) Heartbeat (สคริปต์ในเกม)

1. เมนู 6 → `h` → เปิดใช้ → เลือก "สร้างไฟล์ .lua" (ได้ไฟล์ใน `RejoinTool/heartbeat/<แพ็กเกจ>.lua`)
2. นำสคริปต์ของแต่ละโคลนไปรันใน executor ของโคลนนั้น
3. โปรแกรมรับที่ `127.0.0.1:8765` (`/hb`, `/ping`) เท่านั้น ไม่เปิดสู่เครือข่ายภายนอก

กติกา: เคยส่ง heartbeat แล้วเงียบเกิน timeout (90 วิ) หรือรีจอยแล้วไม่มี heartbeat เกิน grace = ล้มเหลว
ถ้าโคลนนั้น **ไม่เคย** ส่งเลย จะกลับไปใช้วิธีตรวจอื่น (ไม่เกิดลูป rejoin ไม่รู้จบ)

> ⚠️ **คำเตือน:** executor อาจผิดกฎของ Roblox และเสี่ยงถูกแบนบัญชี ใช้ด้วยความเสี่ยงของคุณเอง ฟีเจอร์นี้ปิดเป็นค่าเริ่มต้น

## 6) Performance (เมนู 6 → `p`)

- เคลียร์ RAM (root): `drop_caches` ทุก 30 นาที และ/หรือเมื่อ RAM ว่าง < 300 MB (ห่างกันอย่างน้อย 1 นาที), `am kill-all` ปิดเป็นค่าเริ่มต้น (อาจฆ่าโคลนที่รันเบื้องหลัง), มีปุ่ม "เคลียร์ตอนนี้" และ log ค่าก่อน/หลัง
- ลด CPU: snapshot โปรเซสครั้งเดียวต่อรอบแชร์ให้ทุกอินสแตนซ์, ตรวจตามตารางเวลาร่วม, `os.nice(10)`, แคช presence 60 วิ, รีเฟรชแผง 2 วิ

---

## 7) Discord webhook (เมนู 7)

- เปิด/ปิดรายเหตุการณ์: เริ่ม, หลุด, รีจอย, หยุด และรายงานสถานะ
- ตรวจรูปแบบ URL, มีปุ่มทดสอบส่ง, แนบภาพหน้าจอ (root เท่านั้น)
- รายงานสถานะ + ภาพเต็มจอทุก N นาที (ค่าเริ่มต้น 10, `webhook.periodic_min`, 0 = ปิด) — non-root ส่งข้อความล้วน
- จัดการ HTTP 429 ด้วยการรอแล้วลองใหม่ และส่งเหตุการณ์หยุดแบบ synchronous

## 8) แก้ปัญหาที่พบบ่อย

| อาการ | สาเหตุ / วิธีแก้ |
|---|---|
| `ไม่พบโมดูล Python: rich` (หรือ requests) | `pip install -r ~/requirements.txt` — ถ้าไม่มีไฟล์ ให้รัน `curl -Ls <REPO_RAW_BASE>/requirements.txt -o ~/requirements.txt` ก่อน |
| `CANNOT LINK EXECUTABLE` | รันผ่าน `su` แล้วไลบรารีหาไม่เจอ: `export LD_LIBRARY_PATH=/data/data/com.termux/files/usr/lib` ก่อนรัน python (หรือเพิ่มใน `su -c "..."`) |
| `su` ไม่ได้รับสิทธิ์ / โหมดขึ้น non-root | เปิด root ใน UG Phone แล้วรัน `su -c id` ใหม่ กด "Grant" ให้ Termux, ตรวจว่าติดตั้ง `tsu` แล้ว |
| เขียนไฟล์ไม่ได้ / ไม่เห็น `/sdcard` | รัน `termux-setup-storage` ใหม่ แล้วกดอนุญาต; โปรแกรมจะ fallback ไป `~/RejoinTool` อัตโนมัติ |
| ไม่พบแพ็กเกจ | non-root บางเครื่องมองไม่เห็นแอปอื่น → ใช้เมนู 4 แล้วพิมพ์ชื่อแพ็กเกจเอง (เช่น `com.roblox.client,com.roblox.clienu`) |
| Deep link ไม่ทำงาน | ตรวจลิงก์ในเมนู 3 ใช้ Place ID ทดสอบก่อน; โปรแกรมจะ fallback ไป monkey (เปิดแอปได้แต่ไม่เข้าเกมเอง) — ตรวจว่าแอป Roblox ล็อกอินอยู่ |
| Heartbeat ไม่เข้า | ตรวจว่าเปิดใช้และพอร์ตตรงกับในสคริปต์ (สร้างไฟล์ใหม่หลังเปลี่ยนพอร์ต), ID ในสคริปต์ต้องเป็นชื่อแพ็กเกจ, executor ต้องรองรับ `request`/`HttpGet` ไปยัง `127.0.0.1`, ทดสอบด้วย `curl http://127.0.0.1:8765/ping` ต้องได้ `pong` |
| Webhook ส่งไม่ได้ | ตรวจ URL (`https://discord.com/api/webhooks/...`), ใช้ปุ่มทดสอบ, ดู `logs/rejoin.log`; ถ้าเจอ 429 โปรแกรมจะรอแล้วลองใหม่ |
| ฉีดคุกกี้ไม่สำเร็จ | ต้อง root และเปิดแอปโคลนนั้นอย่างน้อย 1 ครั้งก่อนเพื่อให้มีไฟล์ `Cookies` |
